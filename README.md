# (附文档)Springboot3+Vue3+MySQL 运动爱好系统

**技术栈**：Springboot3、Vue3、MySQL

### 系统简介

本系统是一个基于 Springboot3 + Vue3 + MySQL 前后端分离架构的运动爱好社区平台。系统包含普通用户端和管理员端两大角色，支持运动动态发布、运动活动组织与报名、运动搭子匹配、运动资源共享等核心场景，为运动爱好者提供一站式社交与服务闭环。
 
### 核心功能
 
### 普通用户端

 
- 查看运动动态列表（支持按分类/关键词筛选），进入详情页可浏览完整内容、作者信息及互动数据。 
- 发布运动动态，填写标题、正文、分类及图片，发布后自动计入浏览/点赞/收藏/评论计数。 
- 编辑或删除自己发布的动态（删除逻辑将状态置为0，非物理删除）。 
- 对任意动态进行点赞/取消点赞、收藏/取消收藏操作，前端实时反馈计数变化。 
- 在动态详情页查看评论列表（按时间正序排列），并发表评论或删除自己的评论。 
- 查看运动活动列表（支持按运动类型/关键词筛选），活动卡片显示组织者昵称、头像及当前报名人数。 
- 报名参与活动（需活动状态为报名中且未满员），可取消报名，报名/取消后实时更新活动当前人数。 
- 查看活动详情页，包含活动地点、时间、截止日期、等级要求及已报名成员列表。 
- 接收活动组织者发送的活动通知（站内信），支持标记已读并查看未读通知数量。 
- 发布运动搭子匹配需求（填写运动类型、等级、地区、可约时间及描述），可编辑或关闭自己的匹配需求。 
- 浏览所有公开的匹配需求列表（支持按运动类型/等级/地区筛选），查看发布者的昵称、头像及个人信息。 
- 向匹配需求发布者发送邀约（附留言），并查看自己发起的及收到的所有邀约记录。 
- 处理收到的邀约（同意/拒绝），状态变更后双方均可在记录中查看。 
- 查看运动资源共享列表（支持按资源类型/运动类型/关键词筛选），资源类型可区分场地/教练/装备等。 
- 发布运动资源（填写标题、描述、图片、类型、运动分类、地区及联系方式），可编辑或删除自己的资源。 
- 对资源进行收藏/取消收藏，并在详情页查看资源评价列表（含评分）及发表评价。 
- 个人中心查看/编辑个人资料（昵称、头像、手机、邮箱、性别、擅长运动、运动等级、地区、个人简介）。 
- 修改登录密码（需验证原密码）。 
- 查看自己发布过的所有动态列表。 
- 查看自己发布过的所有匹配需求列表。 
- 文件上传接口（支持上传图片/文档等，返回可访问的URL路径）。
 
### 管理员端

 
- 登录后台控制台，首页展示系统概览统计：用户总数、动态总数、活动总数、资源总数。 
- 用户管理：查看用户列表（支持按用户名/昵称/手机号关键词搜索及按角色筛选），可启用/禁用用户账户（状态切换）。 
- 用户角色管理：修改任意用户的角色标识（例如 USER/ADMIN）。 
- 动态管理：查看所有动态列表（支持按标题/内容关键词搜索及按状态筛选），可审核通过/驳回/下架动态（状态值变更）。 
- 活动管理：查看所有活动列表（支持按关键词及状态筛选），可审核通过/驳回/下架活动。 
- 资源管理：查看所有资源列表（支持按关键词及状态筛选），可审核通过/驳回/下架资源。
 
### 技术栈

 后端框架Spring Boot 3.x ORMMyBatis-Plus（自动分页、Lambda 查询） 权限认证JWT Token（登录拦截器 + 管理员拦截器） 密码加密自定义 PasswordUtil（BCrypt 风格） 前端框架Vue 3（Composition API + setup） UI 组件库Element Plus 前端路由Vue Router 4（History 模式 + 路由守卫） 状态管理Pinia（用户状态 store） 构建工具Vite 数据库MySQL 8.x（MyBatis-Plus 自动建表） 文件上传MultipartFile 本地存储（配置最大 10MB） 跨域处理全局 CORS 配置（允许所有来源及常用方法）
